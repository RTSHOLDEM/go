# go links

taap.it-style links: open a YouTube video straight in the YouTube app from an Instagram story.

New link: `tools/new.sh <slug> <videoId> "<title>"` -> https://rtsholdem.github.io/go/<slug>/

Android: intent:// to the YouTube app, web fallback. iPhone: youtube:// scheme, web fallback after 2.5 s. Desktop: plain redirect.
